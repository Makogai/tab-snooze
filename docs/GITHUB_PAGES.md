# GitHub Pages

1. Repo **Settings → Pages** → Source: **Deploy from branch**
2. Branch: `main`, folder: `/docs`
3. Site URL: `https://<user>.github.io/tab-snooze/`

`docs/version.json` is updated on each `npm run build` from `package.json`.

Site styles load from **jsDelivr** (`@makogai/extension-brand` docs CSS) — not committed in this repo.
